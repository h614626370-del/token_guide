quick-start.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-your-api-key",
  baseURL: "https://llapi.org/v1"
});

const result = await client.chat.completions.create({
  model: "your-model",
  messages: [{ role: "user", content: "Hello" }]
});

灵链云 Token 中转站与 AI API 中转服务

灵链云是面向 AI 应用开发者、团队和自动化工具的 Token 中转站。通过一个 Base URL 和一枚 API Key，可以接入 Claude API、GPT API、Gemini API，以及 Embedding、Image 和 Audio 等接口能力。控制台集中记录 Token 用量、请求状态、余额与费用，便于按应用或成员管理 API Key。适用于 AI 编程助手、知识库问答、内容生成、数据分析、图片生成、语音处理、企业内部工具和多模型测试。
