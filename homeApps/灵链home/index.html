Two-minute migration

三步接入，不打断现有开发节奏。

常见客户端和 SDK 无需大改，只要把鉴权和请求地址指向灵链云，即可开始选择模型。

01
创建 API Key按应用或成员拆分密钥，权限与消耗更清楚
02
替换 Base URL将请求地址设置为 https://llapi.org/v1
03
选择模型开始调用按任务在 GPT、Claude、Gemini 等能力之间切换
quick-start.js
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-your-api-key",
  baseURL: "https://llapi.org/v1"
});

const result = await client.chat.completions.create({
  model: "your-model",
  messages: [{ role: "user", content: "Hello" }]
});
